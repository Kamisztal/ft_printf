# Libft

## Description
Libft is my own C library, the objective is to recode from scratch the Libc. It is meant to be reused in future 42 projects.

## Instructions
Compile the library:
```
make
```
This creates a `libft.a` file.

Other commands:
- `make clean` : removes object files
- `make fclean` : removes object files and `libft.a`
- `make re` : rebuilds everything
